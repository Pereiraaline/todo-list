# Todo List

Aplicação web simples para gerenciamento de tarefas diárias, desenvolvida com HTML, CSS e JavaScript puro. Permite criar, editar, remover e marcar tarefas como concluídas, com persistência de dados no navegador por meio do LocalStorage.

## Funcionalidades

- Adicionar nova tarefa com título, categoria e horário  
- Editar tarefas existentes  
- Remover tarefas  
- Marcar tarefas como concluídas  
- Exibição automática da data e hora atuais  
- Armazenamento local dos dados (LocalStorage)

## Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (ES6)  
- Font Awesome (ícones)
